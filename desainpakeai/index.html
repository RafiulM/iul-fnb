Kedai Senja

Satu sistem untuk pesanan QR, layar kasir, dan laporan pemilik.

Kumpulan prototipe halaman utama berdasarkan PRD IUL FnB. Semua data adalah contoh dan disimpan di browser, jadi aman dicoba.

Scan QR→Pesan→Kasir proses→Diantar
Coba alur real-time

Buka Layar Kasir dan Menu Pelanggan di dua tab (atau dua jendela berdampingan). Kirim pesanan dari menu pelanggan, lalu pesanan langsung muncul di kasir. Ubah statusnya di kasir, dan layar pelanggan ikut berubah.

Masuk sebagai

App Pelanggan (QR)

Dibuka di ponsel setelah scan QR meja, tanpa install aplikasi

App Kasir

Layar utama kasir untuk memproses pesanan

Pengelolaan Pemilik

Menu, stok, penjualan, akun, dan pengaturan

Prototipe statis (HTML, CSS, JS tanpa framework) untuk divalidasi sebelum diimplementasikan di stack TanStack + Node.js + PostgreSQL. Struktur data contoh mengikuti skema PRD §6. Data perubahan hanya tersimpan di memori halaman, kecuali sinkronisasi pesanan antar tab yang memakai localStorage. QR code yang ditampilkan adalah ilustrasi.
